# События C++ → Java

Бот (`core/`) публикует события через **ZeroMQ PUB** на `tcp://127.0.0.1:5555`
(`telemetry.zmq_endpoint` в конфиге бота). Аналитика (`analytics/`) подключается
сокетом **SUB** и подписывается на всё.

- Одно сообщение = один JSON-объект, кодировка UTF-8, без префикса темы.
- Поле `type` определяет вид события.
- `ts_ms` — время на стороне бота, миллисекунды Unix epoch.
- `run` — идентификатор запуска бота (время старта, мс). Номера возможностей (`id`)
  уникальны только внутри одного запуска, поэтому ключ в базе — пара `(run, id)`.
- Большие целые (wei, sqrtPriceX96, ликвидность) передаются **строками в десятичной
  записи**, чтобы не терять точность. Значения для графиков дублируются обычными
  числами с суффиксом `_human` или в единицах токена.
- Адреса в нижнем регистре с `0x`.
- Доставка не гарантирована: если Java не запущена или не успевает, события теряются.
  Бот от этого не зависит.

## `pool_snapshot`

Состояние пула после блока, в котором он изменился. Отправляется также для всех пулов
при старте бота.

```json
{"type":"pool_snapshot","ts_ms":1793300000000,"block":519432121,
 "pool":"0xc6962004f452be9203591991d15f6b388e09e8d0","pair":"WETH/USDC","fee":500,
 "price":2342.57,"tick":-198736,
 "sqrt_price_x96":"3833558700599279129460736","liquidity":"3883490737149040689"}
```

| поле | смысл |
|---|---|
| `fee` | комиссия пула в сотых долях б.п.: 500 = 0.05% |
| `price` | цена token1 за token0 с учётом decimals (USDC за WETH) |

## `opportunity`

Найденный арбитражный цикл, прошедший порог прибыли. Своп `amount_in` токена
`token_in` в `pool_a`, затем обратно в `pool_b`.

```json
{"type":"opportunity","ts_ms":1793300000000,"run":1793299000000,"id":12,"block":519432121,"pair":"WETH/ARB",
 "pool_a":"0x…","fee_a":500,"pool_b":"0x…","fee_b":100,
 "token_in":"0x912ce59144191c1204e64559fe8253a0e49e6548","symbol_in":"ARB",
 "amount_in":"5713349708674793500","amount_out":"5730730000000000000",
 "gross_profit":"17380291325206500","gas_cost":"96404000000000000","net_profit":"-79023708674793500",
 "amount_in_human":5.7133,"net_profit_human":-0.079,"net_profit_weth":-0.000006,
 "compute_us":846}
```

`compute_us` — время принятия решения в боте: от события пула до готового расчёта.

## `execution`

Попытка исполнения возможности (этапы 7–8).

```json
{"type":"execution","ts_ms":1793300000000,"run":1793299000000,"opportunity_id":12,"status":"sent",
 "tx_hash":"0x…","nonce":7,"gas_limit":420000,"max_fee_per_gas":"20000000",
 "error":"","simulate_us":3100,"sign_us":45,"send_us":2900}
```

`status`: `sent` (отправлена), `simulation_failed` (eth_call откатился, не отправляли),
`send_failed` (нода отвергла транзакцию).

## `tx_result`

Транзакция попала в блок.

```json
{"type":"tx_result","ts_ms":1793300000000,"run":1793299000000,"opportunity_id":12,"tx_hash":"0x…",
 "success":true,"block":519432125,"gas_used":231000,"effective_gas_price":"10000000",
 "realized_profit":"17000000000000000","realized_profit_weth":0.0000012}
```

`realized_profit` — фактическое изменение баланса `token_in` у контракта-исполнителя,
`realized_profit_weth` — то же в WETH за вычетом газа.

## `heartbeat`

Раз в ~40 блоков (~10 секунд на Arbitrum).

```json
{"type":"heartbeat","ts_ms":1793300000000,"run":1793299000000,"chain_id":42161,"block":519432160,
 "pools":20,"mode":"monitor","dropped_events":0}
```

`mode`: `monitor` (только поиск) или `execute` (с отправкой транзакций).
